# THE VEIL

A first-person, low-poly, pixel-textured survival-horror game set in the fictional town of Greyhaven
(Godot 4.3, Compatibility renderer).

| Document | Contents |

## Layout

* **Project root:** the Godot project (`project.godot`). The main scene is `game/scenes/MainMenu.tscn`.
* **`THE_VEIL_ASSETS_V2/`:** asset Packs 01-09, each with its generator scripts and validation reports.
* **`docs/`:** GitHub Pages: the asset gallery and the browser build (`docs/play/`).
