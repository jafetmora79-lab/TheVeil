# THE VEIL character screenshots

Rendered from the repository's actual GLB character models at commit `3bcf31b6c53b687bd0da969eee1129100cb2515f`
(default branch `claude/practical-cray-hi2y54`). Neutral lighting, full-body framing,
original embedded textures; these are model screenshots, not generated character art.

`current/` contains the ten unversioned full-body character assets.
`alternates/` contains fourteen versioned full-body models, including Marcus run variants.
The first-person arms-only assets and the separate work prototype are excluded.

See the two lineup images for labeled overviews. Captured in Godot 4.6.3 GL Compatibility.
No game source or character assets were modified.
