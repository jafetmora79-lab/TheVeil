The asset commit updates `furniture.py` and `veh_models.py`, twelve furniture GLBs and their OBJ counterparts, the protagonist sedan GLB, fourteen house furnishing batches, the corner counter material mappings, and the generated manifests. The player home uses individual furniture scenes, so its existing scene references pick up the replacement GLBs directly. The gameplay commit contains the player, world, sedan and opening test scripts.

Godot 4.7.2 imported the project and ran the full opening test with zero failures. The autopilot completed the opening route in 83.15 seconds at a 50 km/h cap, including the driveway exit and reentry sequence. The local test redirected the save file to the test project's cache because the sandbox could not write to the usual user directory. Godot emitted a certificate-store warning and reported two leaked instances at teardown. The 27 changed GLBs passed header, index, finite UV, unit normal, image path, material name, node transform, interaction metadata and collision comparison checks. This was a structural check. A rendered comparison and a human playthrough were unavailable, and no Web build was tested.

To reproduce in a disposable Godot profile, run `godot --headless --path . --import` and then `godot --headless --path . --fixed-fps 60 --script res://game/tests/opening_test.gd -- 50`. For manual testing, start the opening, get the keys, enter the sedan, press E at rest, walk away, reenter, drive to the supermarket, stop, and repeat. Park beside an obstacle to exercise the alternate side. Save while seated and continue from the main menu to check the restored state. Inspect the repaired assets in Godot with the oven and microwave doors open and closed.
